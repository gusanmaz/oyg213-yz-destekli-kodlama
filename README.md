# ÖYG213 · Yapay Zeka Destekli Yazılım Geliştirme — Ders Notları

Anadolu Üniversitesi Bilişim Teknolojileri MYO, ÖYG213 dersinin **Büyük Dil Modelleri (LLM)** ünitesinin ders notları.

**Okumak için:** <https://gusanmaz.github.io/oyg213-yz-destekli-kodlama/>

Hazırlayan: Güvenç Usanmaz.

## Katkı

Bu notlar yapay zekâ araçlarının yardımıyla hazırlanmıştır; **içerikte hata olabilir** ve rakamlar, model adları
hızla eskir. Hata gördüyseniz, anlaşılmayan bir yer varsa ya da daha iyi bir örnek, görsel veya kaynak biliyorsanız
[issue açın](https://github.com/gusanmaz/oyg213-yz-destekli-kodlama/issues) ya da pull request gönderin.

Notların kaynağı `kaynak/` klasöründeki Markdown dosyalarıdır (`n1.md` … `n6.md`); `index.html` bunlardan üretilir.
Düzeltme önerirken Markdown dosyasını değiştirmeniz yeterlidir.

## Görseller

Üçüncü taraflara ait görseller (ders slaytları, makale şekilleri, ekran görüntüleri, karikatürler, fotoğraflar,
logolar) eğitim amacıyla ve her birinin altında kaynağı belirtilerek kullanılmıştır; hakları sahiplerine aittir.
Bir görselin kaldırılmasını isterseniz issue açmanız yeterlidir.
